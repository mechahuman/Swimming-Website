# AquaPulse Swim Club

## Overview

**AquaPulse Swim Club** is a modern, dynamic website template built for swimming clubs and aquatic venues. The design features sleek animations, smooth transitions, and a vibrant aquatic theme to create an engaging, immersive user experience. It showcases the club’s offerings, including swimming lessons, events, and cultural activities.

## Key Features

- **Interactive Animated Cursor**  
  A custom animated cursor (`#cursor`) adds a unique and interactive visual element to the UI.

- **Scroll-Triggered Animations**  
  Smooth background and navbar color transitions powered by GSAP and ScrollTrigger, enhancing user engagement during scroll.

- **Auto-Scrolling Marquee**  
  A horizontal marquee (`#scroller`) highlights key services with hover-triggered color changes for dynamic emphasis.

- **Full-Screen Hero Section**  
  Bold typography and a striking background image with the message “EAT. DRINK. SWIM.” create a memorable first impression.

- **Responsive Layout**  
  Designed to adapt across different screen sizes. Mobile responsiveness is supported, with opportunities for further optimization.

## Design & Content

- **Visual Style**  
  High-quality imagery of swimming pools and venues establishes an aspirational, clean aesthetic.

- **Typography**  
  Strong, uppercase headings with dual-color and stroke effects ensure clarity and visual hierarchy.

- **About Us Section**  
  A clean, two-column layout featuring media on one side and centered descriptive text for balanced presentation.

## Technical Implementation

- Developed using **HTML**, **CSS**, and **JavaScript** (no external frameworks).
- GSAP and ScrollTrigger power animation and scroll-based transitions.
- Fixed navigation bar with hover-based interactivity and style changes.
- Lightweight and performance-conscious design.
